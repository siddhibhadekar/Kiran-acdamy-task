# CareerBridge – Recruitment & Placement Management System

A web-based system to manage the complete campus recruitment and placement cycle, from candidate registration to job offers and joining.

Developed by **Siddhi Bhadekar** at **Kiran Academy**.

## Features

- **Login:** role-based access (Admin, Recruiter, Placement Officer)
- **Dashboard:** totals, recruitment funnel, upcoming interviews and recent placements
- **Candidates:** add, edit, search and view candidate profiles
- **Companies:** manage companies and HR contacts
- **Jobs:** create jobs with package, eligibility criteria and deadlines
- **Applications:** track applications, check eligibility, shortlist or reject
- **Interviews:** schedule, reschedule and record feedback
- **Placement Process:** interview result, offer details and joining
- **Reports:** funnel, company-wise and technology-wise placement, recruiter performance

## Workflow

`Applied → Shortlisted → Interviewed → Selected → Offered → Joined → Placed`
